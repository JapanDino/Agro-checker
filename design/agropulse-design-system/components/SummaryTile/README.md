Плитка сводки с крупной цифрой: сколько полей в каждом статусе.

**Что передаёт потребитель:** `label` — название («Риск»); `value` — число; `hint` — короткое пояснение под цифрой; `status` — `risk` | `check` | `normal` или без него для нейтральной плитки.

- Ставьте плитки рядом в `.ap-tiles` в порядке Риск → Проверить → Норма → Нет правил.
- Цифра — табличная, без единиц; единицы и срок в `hint`.
