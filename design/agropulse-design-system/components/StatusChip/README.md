Плашка статуса поля: «Риск», «Проверить», «Норма», «Нет правил».

**Что передаёт потребитель:** `status` — `risk` | `check` | `normal` | `none`; `children` — свой текст вместо стандартного (необязательно).

- Статус всегда со словом и точкой: красный и зелёный «Пульса» почти равны по светлоте, цвет в одиночку не различить.
- Статус значит «осмотреть первым», не диагноз. Не пишите «Болезнь» или «Опасно».
- `none` — для культур, к которым нет правил (например, кукуруза).
