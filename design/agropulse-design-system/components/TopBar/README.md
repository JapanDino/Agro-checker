Шапка: знак AgroPulse, хозяйство и инструменты справа.

**Что передаёт потребитель:** `farm` — название хозяйства; `farmDetail` — сколько полей и что растёт; `children` — кнопки справа (`soft`, `secondary`).

- Высота 72 px, фон `paper`, нижняя линия `line`.
- На телефоне хозяйство и кнопки с классом `ap-hide-sm` скрываются.
