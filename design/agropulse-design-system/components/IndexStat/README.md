Значение спектрального индекса (NDVI, NDMI) с изменением.

**Что передаёт потребитель:** `label`; `value` — строка с десятичной запятой («0,62»); `change` — разница и период; `trend` — `up` | `down`.

- Две плитки в ряд — `.ap-index-grid`.
- Стрелка и слово дублируют цвет: падение — «↓» и `risk-ink`, рост — «↑» и `green-press`.
