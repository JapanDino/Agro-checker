Переключатель из 2–5 взаимоисключающих вариантов: фильтр очереди, вкладки панели, индекс.

**Что передаёт потребитель:** `options` — `[{value, label}]`; `value` + `onChange` (управляемый) или `defaultValue`; `label` — подпись для экранного диктора; `wide` — на всю ширину контейнера.

- Подписи короткие, одно-два слова: «Рядом» / «С разделителем».
- Больше пяти вариантов — используйте `TextField` с `options`.
