Кнопка действия: основная зелёная, вторичная серая, мягкая зелёная и текстовая ссылка.

**Что передаёт потребитель:** `children` — подпись глаголом («Сравнить снимки», «Отметить осмотр»); `variant` — `primary` | `secondary` | `soft` | `text`; `size` — `sm` (40 px, внутри карточки поля) | `md` (48 px) | `lg` (54 px, итоговое действие панели); `wide` — на всю ширину; `icon` — имя иконки (`analysis`, `map`, `arrow`…); любые атрибуты `<button>`.

- Одна `primary` на карточку или панель — главное действие. Остальные — `secondary`.
- `soft` — для режимов и подсказок в шапке («Архивный пример»), не для сохранения.
- `text` — переход к другому экрану со стрелкой: «История этой площади →».
- Неактивная кнопка говорит, чего не хватает: «Выберите итог осмотра», а не «Сохранить» серым.
- Высота 48 px — чтобы попадать пальцем в поле, в том числе в перчатках.
