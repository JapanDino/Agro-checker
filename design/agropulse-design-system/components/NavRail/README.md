Навигация по рабочим разделам: вертикальная колонка на компьютере, нижняя панель на телефоне.

**Что передаёт потребитель:** `items` — `[{id, label, icon?, badge?}]`, `icon` по умолчанию равен `id` (`map`, `today`, `trips`, `analysis`, `task`, `history`); `active` + `onChange` или `defaultActive`; `horizontal` — нижняя панель.

- Порядок разделов — путь агронома: Карта → Сегодня → Выезды → Анализ → Задача → История.
- `badge` — число полей «Риск» на «Сегодня»; только для того, что требует действия.
- На телефоне оставьте 4 раздела.
