Экран «Сегодня» целиком: шапка, навигация, сводка, очередь полей и боковая панель с индексами, отметкой осмотра и почасовым основанием.

**Что передаёт потребитель:** ничего — это образец компоновки на данных-примерах. Соберите свой экран из тех же компонентов.

- Сетка: колонка навигации `rail` 96 px, основная область с отступами `space-8` / `space-9`, справа панель `side-panel` 340 px.
- Сверху вниз: заголовок и дата расчёта → сообщение об источнике → плитки сводки → фильтр → карточки полей.
- Уже 980 px панель уходит под очередь, уже 720 px навигация скрывается (на телефоне — `NavRail` с `horizontal` внизу).
- Цифры в примере иллюстративные.
