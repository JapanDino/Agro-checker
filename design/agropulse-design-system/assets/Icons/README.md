# Иконки

Линейные иконки разделов из боковой навигации: поле 24 × 24, линия 1,8 px, скруглённые концы и стыки, без заливки. Краска в файлах — `ink-2` (#3B4741); в интерфейсе иконка берёт цвет текста (`currentColor`), а на активной плитке становится белой на `green`.

| Файл | Раздел |
| --- | --- |
| `map.svg` | Карта — выбрать площадь |
| `today.svg` | Сегодня — очередь полей по риску |
| `trips.svg` | Выезды — собрать выезд |
| `analysis.svg` | Анализ — сравнить снимки |
| `task.svg` | Задача — задача на осмотр |
| `history.svg` | История — наблюдения по месту |

Иконка всегда стоит рядом с подписью. Плитка под иконкой — 42 × 42, скругление 13 px, фон `soft`.
