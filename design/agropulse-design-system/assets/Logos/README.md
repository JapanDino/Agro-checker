# Логотипы

`agropulse-symbol.svg` — знак AgroPulse: три ростка белой линией на плитке `green` 42 × 42 со скруглением 13 px. Ставится в шапке слева, рядом со словом «AgroPulse» (Manrope 800, 21 px, `ink`) и подписью «ONLYFARMS» (700, 9 px, разрядка 0,18em, `muted`).

`agropulse-sprouts.svg` — тот же рисунок без плитки, одна краска `green` (#1E9B4B). Для светлых поверхностей `paper`, `bg`, `soft`. Словесного логотипа отдельным файлом нет: название всегда набирается шрифтом.
