AGROPULSE / ONLYFARMS — продукт для самостоятельной проверки
Сборка 6 ноября 2026. Архивный прототип, не текущий прогноз болезни. Обновлено оформление; данные и модели сохранены.

НАЗНАЧЕНИЕ
Подготовить обследование хозяйства и пилот датчиков: сравнить наблюдения на общих датах, выбрать места, сохранить вопросы, сформировать маршрутный лист и вести историю настоящих посещений.

БЕЗ УСТАНОВКИ
Открыть preview.html — четыре настоящих экрана продукта и описание сценария. Это статический просмотр, не интерактивная карта. Для работы с данными и формами нужен запуск ниже.

ТРЕБОВАНИЯ И ЗАПУСК
Проверяемая комплектация: Windows x64, Python 3.13 x64, современный браузер. Интерпретатор Python в архив не включён. Если его нет, установить официальный Python 3.13 с python.org. Другие ОС и версии интерпретатора в этой офлайн-комплектации не проверены.
1. Полностью распаковать ZIP в доступную для записи папку. Не запускать внутри ZIP.
2. Запустить START.cmd. Либо: py -3.13 -X utf8 launch.py
3. Первый запуск создаст .review-venv и установит библиотеки из wheels. Сеть для установки библиотек и работы с готовым архивом не нужна. Не обновлять зависимости вручную.
4. Открыть http://127.0.0.1:8771/scouting
5. Окно запуска держать открытым. Для остановки нажать Ctrl+C.
Другой порт: py -3.13 -X utf8 launch.py --port 8773
Проверить контрольные суммы без запуска: py -3.13 launch.py --verify-only
Для другого журнала: py -3.13 launch.py --directory "C:/папка/мой-журнал"
Приложение принимает соединения только с этого компьютера. Публичный сервер и учётные записи не создаются.

ПРОВЕРКА ЗА ПЯТЬ МИНУТ
1. Открыть карту. Осенью 2026 по умолчанию: 26 сентября → 11 октября, около 15 дней, пригодны 27/27 обводок.
2. Переключить весну 2024. По умолчанию: 12 мая → 27 мая, пригодны 13/27. Серые площади — отсутствие пригодной общей пары, без подмены другими датами. 13/27 — полнота данных, не точность модели.
3. Вернуть 2026, выбрать R11. Открыть сравнение: ΔNDMI площади около −0,077. Это другая пара, чем пример R11 21 сентября → 14 октября в прежних материалах, поэтому цифры различаются.
4. Выбрать место на карте снимка; увидеть отдельную сводку окна 60 м. Если окно не покрыто, так и написано.
5. Для проверки форм создать задачу с явной пометкой «ТЕСТ комиссии — не реальный осмотр», указать собственный вопрос. Это будет запись только в локальном review-journal, не в журнале хозяйства.
6. Раздел «План»: выбрать 1–3 разные задачи, назвать план, выбрать цель и сохранить. Скачать HTML-лист, JSON с источниками и точки GeoJSON. HTML можно распечатать через браузер. Порядок мест не оптимизирует дороги.
7. Открыть задачу и историю. Посещений нет, пока человек не внёс реальную запись. Для демонстрации формы без посещения использовать «Посмотреть форму результата» в пустом журнале. Не сохранять технический тест как фактическое посещение.
8. Перезапустить приложение: ваши задачи и планы останутся в review-journal. История работы команды/агронома в поставку не включена.

ПЛАН ДАТЧИКОВ
Карта «Места для обследования» показывает предварительные кандидаты по DSM. Сохраните выбранные точки как задачи и объедините планом «Места под датчики». В лист добавятся вопросы о поверхности, доступе, связи, питании и монтаже. Эффективность размещения и пригодность точек не подтверждены.

ДАННЫЕ И ОГРАНИЧЕНИЯ
27 обводок R01–R27 восстановлены по скриншоту, не подтверждены как границы или номера полей. Культуры и фазы не определяются автоматически.
Sentinel-2 L2A: 92 сохранённых растров индексов, маски облаков/теней, сетка 20 м; для сводки площади >=10 общих пригодных ячеек и >=80% покрытия. Для окна 60 м >=5 ячеек и >=80%. Остаточные облака возможны. Разная версия обработки не получает численное сравнение в общем обзоре.
Изменение — медиана попиксельной разности. Оно может отличаться от разности двух показанных медиан. Направление и величина чувствительны к обводке; сценарии смещения не дают статистической гарантии.
Сортировка по изменению/покрытию описывает данные и не является проверенной моделью приоритета осмотров.
Почвы — SoilGrids 250 м, не анализ почвы участка. Высоты — DSM около 30 м, включает растительность/здания; контраст не доказывает микроклимат.
ERA5 — ретроспективная модель на общей ячейке 0,25°, не датчик. 239 полных суток в двух окнах; 17–19 октября 2026 с пропусками. Данные на экране относятся к поздней дате выбранной пары, не к сегодняшнему дню. RH>=90% не является мокрым листом. NDMI не измеряет влажность почвы.
Прогноз болезней, оптимальное размещение датчиков, связь с АгроМон, экономия обработок и обучение по осмотрам — цели будущего пилота. Их качество этим приложением не доказано. Обработка СЗР не назначается.

ПРОВЕРЯЕМОСТЬ
manifest.json: SHA256 и размеры всех поставленных файлов, версии библиотек, список источников. evidence/common-pairs.json: расчёт общей пары. evidence/R11-evidence.json и R11-boundary-scenarios.csv: прежний отдельный пример R11 с другой парой дат. models_changed=false; обученные модели/личные документы/рабочий журнал отсутствуют.
web/scouting/assets/public-context.json и data/farm-research/area-context/satellite.json содержат происхождение данных, даты, версии и хеши. Подложка Esri разновременная, дата её съёмки неизвестна.
Исходный код приложения включён. Технические тесты лежат отдельно от журнала. Автоматические проверки — инженерная проверка, не пользовательское исследование или подтверждение экономии.
Исходные спутниковые и погодные архивы при просмотре не обновляются. Обновление потребует отдельной загрузки/проверки и новой версии поставки.
