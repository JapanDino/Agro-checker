# Рабочее место агронома — макет для компьютера

`index.html` — самостоятельная страница. Откройте её в браузере прямо из папки, сервер не нужен. Шрифт Manrope загружается из Google Fonts; без сети страница использует системный шрифт.

На сервере проекта (`field_server.py`) страница не подключена: его CSP запрещает встроенные скрипты и стили, а макет собран в одном файле. Чтобы отдавать его с сервера, нужно вынести стили и скрипт в отдельные файлы и убрать атрибуты `style` из разметки.

Все данные в макете — **пример**: погода, прогноз, снимки, отметки, паспорта полей. Отметки, задания и настройки хранятся только в браузере (`localStorage`), сбросить их можно в разделе «Данные».

## Что есть

| Раздел | Что делает |
| --- | --- |
| Сегодня | Шкала сезона с данными по датам, очередь «Риск / Проверить / Норма» с окном осмотра и лентой за 14 дней, карточка поля: причины, погода и окна для опрыскивания, снимки NDVI, история и паспорт. «Со вчера / Прогноз / План / Скоро», утренняя сводка. |
| Карта | Спутниковый снимок хозяйства с обводками 27 полей, граница сектора ERA5 и его узел, слои «статус» и NDVI, приближение к полю. |
| Сезон | Матрица «поля × дни»: статус каждого поля по дням, отметки осмотров. |
| Выезд | Автосбор маршрута (сначала «Риск» по сроку, затем ближайшие), маршрутный лист, ссылка в Яндекс Карты, задания на обработку с отметкой «Внесено». |
| Журнал | Осмотры с фильтрами «Тревожные / Очаги / Чисто» и метрикой пилота «сигналы с отметкой». |
| Данные | Покрытие источников по датам, загрузка выгрузки учёта (CSV по шаблону `config/farm_records_template.csv`) с проверкой строк, правила автоматизации. |

Клавиши: `Ctrl K` — поле, дата или команда; `J/K` — поля; `I` — осмотр; `←/→` — дни; `T` — сегодня; `?` — справка.

## Расчёт

Статусы считаются в странице по правилам `config/field_risk_rules.json` в том же порядке, что `agro_checker/field_risk.py`: окно 10 суток, фаза на день события, защита фунгицидом 14 дней включительно, смыв дождём ≥ 10 мм за сутки после обработки, «Проверить» при скором конце защиты после события под ней, частичном событии, неизвестной фазе или очаге за 365 дней. Погода ERA5 одна на сектор; у R07 дни с узла считаются по датчику листа.

Отличия от `field_risk.py`, которые стоит перенести или обсудить:

- если поле прикрыто двумя обработками, берётся защита, которая действует дольше;
- новая обработка снимает «Защита заканчивается» для события под старой;
- окно осмотра начинается через 7 дней после влажной ночи (скрытый период) — допущение агронома, в правилах его нет;
- прогноз на 3 дня и окна для опрыскивания (ветер ≤ 4 м/с, без дождя в этом и следующем интервале, 8–25 °C) — пример; в рабочей версии нужен источник прогноза (GFS/ICON).

Поля R01, R02, R07, R09, R10, R11, R23 и их фазы, обработки и очаги взяты из `config/farm_records_example.csv`; остальные — иллюстрация.

## Карта

Обводки — `web/scouting/assets/public-context.json` (приблизительные, обведены по скриншоту), подложка — вырезка `web/scouting/assets/basemap.jpg` (Esri World Imagery; дата съёмки неизвестна). Пересобрать карту и константу `MAPGEO` в `index.html`:

```bash
python web/workstation/tools/build_farm_map.py
```

## Проверки

Нужен Playwright с Chromium.

```bash
node web/workstation/checks/layout-audit.js
```

```bash
node web/workstation/checks/flows.js
```

Первый ищет наложения, обрезанный текст и горизонтальную прокрутку во всех разделах на ширинах 400–1920 px. Второй проходит прогноз → план обработки → осмотр с решением «обработать» → «Внесено» → журнал → паспорт → сводку.

## Чего не хватает до рабочего продукта

Выводы ревью по сравнению с АгроМоном, xarvio и другими: мобильное приложение офлайн с синхронизацией, определение поля по GPS и фото с координатами, push-уведомления, роли «главный агроном / агроном», интеграция с АгроМоном и 1С, источник прогноза погоды. Вопросы к правилам: отдельные болезни ячменя, частота «половины порога» на реальной ERA5, предшественник и устойчивость сорта.

Дизайн-система, из которой собран макет: [`design/agropulse-design-system`](../../design/agropulse-design-system/README.md).
