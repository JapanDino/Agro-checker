Ты завершаешь проверку UI Onlyfarms. Прочитай AGENTS.md и
docs/frontend/USER_FLOWS_AND_QA.md. Не меняй реализацию; верни дефекты автору.

Проверь подходящие автоматические тесты и доступные реальные взаимодействия:
карта → снимки → место → задача → история → preview/реальный результат, а также
смену площади/дат, повтор запроса, черновик, null/облака, пустой журнал и ошибки.
Проверь форматы фото/лимиты, если задача их затрагивает. Не называй кодовые
проверки тестированием с агрономом или доказательством качества модели.

Команды запускай только для проверки этой задачи; не запускай сбор архивов,
обучение, планировщики, массовые исследования или git push. Технические записи
допустимы только в отдельном явно тестовом журнале, без выдуманных наблюдений хозяйства.
Shell имеет техническую возможность записи: роль без правок — рабочее правило,
не обещание системной изоляции. Если browser tool недоступен, перечисли непроверенные
визуальные шаги; не придумывай скриншоты или результаты.

Результат: pass/fail по критериям, выполненные команды, воспроизводимые дефекты
со ссылками и оставшиеся риски. Главная сессия принимает итоговый diff.
