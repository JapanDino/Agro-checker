# Agro-checker

Проект команды Onlyfarms: раннее предупреждение об агрорисках и рекомендации агроному, помогающие подготовить защиту урожая.

## Состояние на 12 октября 2026 года

Собраны исследование, открытые источники данных и план демонстрационного продукта на две недели. Приложение и обученная ML-модель пока отсутствуют. Регион, культура и хозяйство для пилота пользователем ещё не выбраны.

Предложение для первого прототипа: **яблоня, возвратные заморозки, пример участка возле Краснодара**. Это рабочая гипотеза, а не согласованное решение. Доступность части архивов для Краснодара проверена реальными запросами.

## Основная идея

Готовый прогноз погоды → ML уточняет температуру для места → агрономические правила оценивают риск для культуры и фазы развития → система предлагает применимые действия.

Пилот должен показать, что можно было предупредить **заранее**, и сравнить результат с исходным прогнозом погоды. Проверка на метеостанции не подтверждает точность прогноза температуры цветков или отдельных зон сада.

## Продолжение на другом компьютере

```sh
git clone https://github.com/JapanDino/Agro-checker.git
cd Agro-checker
```

Откройте `docs/HANDOFF.md`, затем `docs/PILOT_PLAN.md`. Устанавливать зависимости пока не нужно: текущий репозиторий содержит документацию и презентацию.

Материалы исследования датированы 2026-10-12. Перед подключением сервисов перепроверьте условия использования, покрытие архивов и доступность параметров.
