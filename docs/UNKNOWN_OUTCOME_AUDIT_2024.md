Причина выбрана по сцене с максимальной пригодной долей ядра в прежнем окне 6–8 дней,
без выбора по величине падения индекса. Защитное расширение маски исключает соседство
всех непригодных классов, поэтому эти восемь случаев нельзя назвать только облачными.
Это причины отсутствия надёжной спутниковой метки, не агрономические диагнозы.

Три старых спорных исхода остаются неизвестными: R12/R13 (1→8 июля) имеют конфликт
масок соседних тайлов; R09 (11→19 сентября) не проходит прежние 80% общего пригодного ядра.
Совпадения части индексов недостаточно, чтобы признать исход известным.

Очереди неизменны: простая база **19 снижений / 49 без снижения / 65 неизвестных**,
исправленный кандидат **23 / 45 / 65**, по 133 выбора при одинаковом бюджете.
Это разработческие результаты 2024, не независимая оценка и не доказательство пользы осмотра.
Аудит не улучшил метрики и не устранил риск систематического смещения из-за пропусков.

Настройки, маски, пороги, диапазоны дат и версии обработки не менялись; интерполяция не
использована. Известные метки и ранжирование сохранены побайтно по смыслу данных.
Новые результаты не поступают в обучение или выбор настроек. 2025–2026 не читались
как исходы аудита. Зафиксированный будущий эксперимент, модели и детектор не изменены.

Воспроизведение аудита выполнялось последовательно:

```powershell

.venv\Scripts\python.exe -X utf8 scripts/audit_unknown_outcomes_2024.py catalogue
.venv\Scripts\python.exe -X utf8 scripts/audit_unknown_outcomes_2024.py collect
.venv\Scripts\python.exe -X utf8 scripts/audit_unknown_outcomes_2024.py run
```

Повторная перезапись снимка каталога/результата заблокирована. Читаемый отчёт можно заново
построить командой `scripts/report_unknown_outcomes_2024.py`: это только экспорт сохранённых
результатов с проверкой исходных хешей, без загрузки данных и обучения.

Следующий источник независимых исходов — будущие выпуски по уже зафиксированному протоколу.
Sentinel-1 может дать дополнительное наблюдение сквозь облака, но не заменяет неизвестный
NDMI/NDVI и требует отдельной задачи, протокола и проверки.
