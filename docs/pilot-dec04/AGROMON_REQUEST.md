# Получение данных АгроМон для пилота

Статус 09.11.2026: доступа нет; выгрузка хозяйства не получена. Ниже подготовленный
текст для владельца аккаунта/поддержки. **Сообщение не отправлено.**

## Минимальный набор

1. Реальные ID/названия и контуры выбранных полей, система координат, сезон.
   Желательные форматы — GeoJSON/KML/KMZ/полный SHP. Это запрос формата;
   наличие такого экспорта в меню АгроМон нами не подтверждено.
2. Культура по каждому полю и сезону; фактические даты посева и уборки, если есть.
   План отдельно от факта. Сначала достаточно 3–5 полей, чтобы проверить сопоставление.
3. Доступные осмотры: исходный ID, поле/точка, дата, наблюдения, автор/роль,
   проверенный статус результата, фото при наличии. Нужны и записи без выявленной
   проблемы; отсутствие записи не означает отрицательный осмотр.
4. Даты фактических операций и их типы. Возможность отличить уборку/обработку
   особенно важна для интерпретации падения индекса.
5. Дата выгрузки, часовой пояс, единицы, момент создания/изменения записей, если он
   есть. Для времени, которого нет, сохраняем unknown, а не подставляем точное число.

Сначала запрашиваем реально существующие записи. Не просим агронома восстанавливать
задним числом точные фазы, координаты или измерения. Доступные 2022–2024 полезны
для разработки; 2025–2026 сохраняются для отдельной оценки без подбора настроек.

## Черновик владельцу аккаунта

Здравствуйте! Для пилота Onlyfarms к 4 декабря хотим проверить подготовку осмотров
на данных вашего хозяйства. Можно ли предоставить выгрузку по 3–5 полям: их ID и
контуры, культуры/сезоны, фактические посев и уборку, операции и имеющиеся осмотры?
Нужны исходные записи, включая обычные осмотры без проблем. Если удобнее, начнём
со стандартного Excel-отчёта АгроМон и карты PDF; структуру разберём самостоятельно.

Пожалуйста, подскажите, кто может разрешить доступ и использование данных для
анализа пилота и возможного обучения. Доступ к чужим хозяйствам не требуется.
Разрешённый доступ к выбранному хозяйству либо выгрузка предпочтительнее передачи
личного пароля. Качество и возможность обучения проверим после получения файлов.

## Черновик поддержке

Здравствуйте! Команда Onlyfarms готовит пилот помощника для подготовки осмотров
совместно с хозяйством-партнёром. Хотим уточнить порядок разрешённого получения
данных при согласии владельца аккаунта:

- возможен ли read-only доступ к полям/контурам, культурам по сезонам, операциям
  и осмотрам выбранного хозяйства;
- какая документация/соглашение/полномочия требуются для API;
- какие стандартные выгрузки дают эти сведения и как получить геометрии с ID;
- есть ли время создания/изменения записи, единицы, часовой пояс и история исправлений;
- какие сервисы и ограничения API действуют сейчас, в том числе спутниковые данные;
- как согласовать использование выгрузок для анализа/обучения в рамках пилота.

Подтверждение полномочий и выбранные поля готовы согласовать с владельцем.
На этом этапе соглашение API ещё не подписано и ключей нет.

Официальная страница порядка доступа: https://agromon.ru/agreementapi
Поддержка на сайте: info@agromon.ru. Обращение отправляет команда после проверки
текста и полномочий. Создание нового аккаунта не открывает записи существующего хозяйства.

## После получения

Сначала сохранить исходный файл, источник/дату и SHA256; затем отдельно описать
колонки и составить явное сопоставление с нашей схемой. До проверки не импортировать
осмотры как обучающие метки и не объявлять приблизительные R01–R27 реальными полями.
Необходима сверка контуров/ID и выбранного сезона. Пустые ячейки не превращать в нули.

Файлы хозяйства, ключи, фото и личные журналы хранятся вне публичного Git. Для
обмена с фронтенд-разработчиком достаточно контракта и обезличенного примера с
разрешения владельца; пароль в переписку не нужен.
