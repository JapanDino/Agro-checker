# Два оформления AgroPulse

С 8 ноября 2026 интерфейс `/scouting` по умолчанию открывается в новом оформлении
«Хай-тек». Это самостоятельная система `web/scouting/hightech.css`, а не каскад
поправок поверх прежнего дизайна. Все пять прежних CSS «Атласа» сохранены без изменений.

## Переключение и быстрый откат

В шапке нажмите **«Дизайн: Хай-тек»**: включится прежний светлый «Атлас».
Повторное нажатие возвращает «Хай-тек». Страница не перезагружается: выбранная
площадь, пара дат, место и текст формы остаются в текущем состоянии. На карте
камера адаптируется к другой компоновке и показывает все площади.

Прямые ссылки:

- Новый: http://127.0.0.1:8770/scouting?design=hightech
- Прежний: http://127.0.0.1:8770/scouting?design=atlas

Выбор запоминается в `localStorage` данного адреса. Параметр `design` в ссылке
имеет приоритет; после ручного переключения он обновляется. При недоступном
хранилище выбор сохраняется в ссылках между картой и страницей источников.
Проверено обновление прямых ссылок и на самостоятельном сервере нового ноутбука.
API архива не принимает параметры оформления; валидация его запросов сохранена.

На новом ноутбуке: остановить сервер → `git pull --ff-only` → `START_SCOUTING.cmd`.
Прежние ZIP со сборками не пересобраны и содержат оформление своего выпуска.

## Что изменилось

- Независимые нейтральные тёмные поверхности и зелёные акценты без внешних шрифтов.
- Постоянная узкая навигация слева; на телефоне — нижняя панель.
- Новая композиция карты, компактный инспектор площади, раскрываемые даты и список.
- Новое оформление сравнения, основания, графиков, задач, истории, планов и диалогов.
- Поддержка клавиатуры, видимый фокус и `prefers-reduced-motion`.
- Рабочий путь: карта → изменение → явный выбор места → задача → история → результат.

Цвета осей/легенды графиков адаптированы к тёмному фону; значения не менялись.
Растры индексов, их шкалы, координаты клика, геометрия, научные расчёты, модели и
правила сохранения посещений прежние. Научные карты сохраняют собственную цветовую
шкалу: зелёная палитра оформления не перекрашивает исходные изображения.

## Контрольная точка кода

Версия до редизайна закреплена тегом **`ui-atlas-before-hightech-2026-11-08`**,
коммит `93bb0ac7b4604313172df7dd689f04f8e6e75632`. Для визуального отката достаточно
кнопки или ссылки выше — журнал при этом не затрагивается.

Если понадобится восстановить именно прежний код интерфейса, сначала сохраните
свои незакоммиченные изменения и остановите сервер. Затем:

```powershell
git fetch --tags
git restore --source=ui-atlas-before-hightech-2026-11-08 -- web/scouting/index.html web/scouting/about.html web/scouting/app.js web/scouting/map.js agro_checker/field_server.py agro_checker/scouting_server.py
```

После перезапуска откроется прежний интерфейс. Новые файлы стилей останутся в
репозитории, но прежний HTML их не подключает. `data/` и локальные журналы эта
команда не затрагивает. Такой откат изменит перечисленные файлы в рабочей копии.

24 Python-теста (архив/задачи/планы и строгие маршруты оформления) и 8 JS-тестов
черновиков. Браузер: реальная карта/сравнение/разделитель, задача, история,
предпросмотр результата, переключение туда-обратно, reload черновика и адаптивность.
Техническая задача и план проверяются только в отдельном журнале; в рабочий журнал
хозяйства примеры осмотров не добавляются. Проверка разработчиком не заменяет
тестирования удобства с агрономом.
