# Демонстрация: три архивные ночи

Продолжительность: 4–5 минут. Все примеры — отложенный сезон 2025, выбраны после проверки как иллюстрации; модель не переобучалась. Названия заранее раскрывают исход: это объяснение результатов, не слепая проверка. Одна успешная ночь не доказывает качество всего пилота.

## Подготовка — 30 секунд

Откройте `dist/pilot/index.html` в обычном браузере. Для HTTP-просмотра:

```powershell
python -m agro_checker ui --serve --port 8765
```

Перейдите в «Архив ночей». Сверху расположены три кнопки примеров. Они меняют дату/сезон и сбрасывают фильтр; фазу яблони и показ наблюдений сохраняют.

Выберите «Полное цветение / после цветения» **как сценарий**. Объясните: журнала фаз сада нет. Порог этой фазы около −2,2 °C — справочное значение, не прогноз ущерба. Для попаданий/пропусков/ложных тревог отдельно проверяется **погодный минимум < 0 °C**. Первая публикация прогноза не восстановлена; доступность в сценарии проверена косвенно по времени архива.

Скажите: «Здесь один выпуск GFS 06:00 UTC на следующую ночь. Выдача в 18:00 МСК — сценарная. Зелёный ряд — GFS, жёлтый — экспериментальная коррекция, синий — последующие наблюдения станции, а не температура цветков».

## Показ — по минуте на пример

| Кнопка | Ночь, МСК | Минимум GFS | С коррекцией | По станции | Итог по 0 °C |
|---|---|---:|---:|---:|---|
| Удачный прогноз | 2–3 марта 2025 | −4,3 °C | −5,0 °C | −4,0 °C | Оба прогноза попали |
| Пропущенный заморозок | 7–8 марта 2025 | +2,9 °C | +2,1 °C | −4,0 °C | Оба прогноза пропустили |
| Ложная тревога коррекции | 4–5 марта 2025 | +0,2 °C | −0,5 °C | +2,0 °C | GFS верен, коррекция дала ложную тревогу |

Для каждой ночи нажмите кнопку, скройте наблюдения переключателем у графика и объясните прогнозную карточку. Затем включите наблюдения и покажите блок «После ночи · проверка по факту». Карточка риска остаётся прежней: последующие измерения не исправляют прогноз задним числом.

**1. Удачный прогноз.** «Оба ряда указывают на воздух ниже нуля и достижение справочного порога нашего сценария. Станция подтверждает охлаждение. Это попадание по событию; в эту ночь исходный GFS ближе к фактическому минимуму, чем коррекция. Повреждения яблони мы не измеряли».

**2. Пропущенный заморозок.** «Оба прогноза положительные, справочный порог не достигнут. После ночи видим −4 °C на станции — охлаждение пропущено. Риск не меняется задним числом; локальные наблюдения и проверка сада необходимы. Этот пропуск нельзя скрывать за улучшением средней ошибки».

**3. Ложная тревога коррекции.** «Сдвиг переводит слабоположительный прогноз GFS ниже нуля. Станция показывает +2 °C. Ложную тревогу дала именно коррекция, исходный GFS здесь верен. При выбранной фазе справочный порог −2,2 °C не достигнут даже в скорректированном ряду: погодная тревога по 0 °C и справочный риск для яблони — разные проверки».

## Завершение — 30 секунд

Откройте «Качество прогноза». На всех 91 полных ночах теста MAE минимума снизилась 1,56 → 1,41 °C; пропуски остались 2 из 6, ложные тревоги выросли 0 → 1, почасовая ошибка ухудшилась. Три примера не заменяют эти метрики.

Скажите: «Пилот воспроизводит исходные прогнозы, показывает ошибки и объясняет фазовый сценарий. Следующий шаг — просмотр карточек агрономом, измерения в саду и сохранение реальных выдач. Спасённый урожай и экономию пока не заявляем».

## Проверка и воспроизведение

Даты/ожидаемые исходы: `config/demo_cases.json`. Сборка вычисляет минимумы из тех же полных рядов, проверяет принадлежность тесту и исходы. Если новый расчёт изменил классификацию, сборка требует пересмотреть подпись. Для отсутствующих/неполных ночей кнопка отключается. Исходные данные и выбранная коррекция не менялись.

```powershell
python -m agro_checker ui
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
node --test tests/test_risk.cjs
```
