# Что заявлено в презентации и что умеет прототип

Сверка слайдов защиты (схема «Как работает», «Решение», «Альтернативы», Lean Canvas, CJM)
с работающим кодом `/scouting`. Статусы совпадают с обзором «Возможности» в интерфейсе.

| Заявление в презентации | Статус | Что работает в прототипе | Чего ещё нет |
|---|---|---|---|
| Узел в точке риска: подсказываем, куда ставить — рельеф, почва, лесополосы, очаги | Частично | `sensor_siting.py`: точки для осмотра перед монтажом по низине/возвышению DSM, высоким объектам у поля (рощи, широкие лесополосы — восстановлены из слоя рельефа 30 м), почве SoilGrids (сравнение площадей между собой) и прошлым очагам из учёта и отметок. Прозрачное правило ранжирования и объяснение. Приём рядов с узла (`POST /api/scouting/sensor-series`) — дни с узлом заменяют ERA5 для поля. | Самого узла с датчиком листа (монтаж — пилот). Узкие лесополосы DSM 30 м не различает; деревья и постройки не отличаются; на склонах (R17, R21–R27) высокие объекты не оцениваются. |
| Данные АгроМон: поля, культура, дата сева, обработки — без повторного ввода | Частично | Загрузка выгрузки CSV (поля и культуры, сев, фазы, обработки, прошлые очаги) с проверкой строк до сохранения; шаблон и пример скачиваются из интерфейса. | Прямого подключения к АгроМон. Формат — шаблон команды, с реальной выгрузкой АгроМон не сверен. |
| Расчёт риска по полю: фаза × часы мокрого листа при нужной температуре × защита | Работает (черновые пороги) | `field_risk.py` + `config/field_risk_rules.json`: бурая ржавчина и септориоз для озимых зерновых, восприимчивость с выхода в трубку, защита фунгицидом 14 дней, смыв дождём ≥ 10 мм. Почасовая ERA5 из репозитория проверяется по SHA-256. | Проверки порогов на контрольных полях (пилот 2027). Без узла погода одна на сектор (ERA5 0,25°), поля различаются только фазой, защитой и данными узлов. |
| Сигнал агроному: поле риск / проверить / норма, причина и срок осмотра | Работает | Экран «Сегодня»: очередь всех обводок, причина, окно осмотра «с … по …» (начало — через 7 дней скрытого периода), почасовое основание. Рабочее место агронома `/workstation/`. | Утреннего push-уведомления. |
| Осмотр «чисто / нашёл очаг» дообучает модель | Частично | Отметки сохраняются (с подтверждением реального осмотра) и считаются метрики пилота: «сигналы с отметкой осмотра», «очаги после сигнала». Очаг поднимает поле в «Проверить». | Дообучения: отметки помечены `model_training_eligible: false`, модель не переобучается. |
| Сравнение снимков, задача на осмотр, история, план выезда | Работает | Как раньше: Sentinel-2, место 60 × 60 м с основанием, история с фото, маршрутный лист. | — |

## Как показать на защите

1. «Возможности» в шапке → схема из презентации со статусами.
2. «Открыть очередь» → «Сегодня», источник «Пример», дата **20 мая 2024**: R11 и R07 — риск,
   R02 и R23 — проверить, R01 и R09 — норма, R10 (кукуруза) — правил нет. Раскройте
   «Почасовое основание» у R11.
3. «На карте» → вкладка «Датчики»: куда ставить узел и почему.
4. «Отметить осмотр» на примере открывается без сохранения; отметки пишутся только для
   загруженных данных хозяйства после реального осмотра.

Пример `config/farm_records_example.csv` — демонстрационный, все поля подписаны «ПРИМЕР»;
сервер отказывается сохранять его в журнал хозяйства.

## Ограничения, которые нужно проговаривать

- Пороги — черновик команды, не проверенная модель болезней и не порог повреждения.
- ERA5 — реанализ, а не измерение на поле; «влажный лист» по ERA5 — косвенный признак
  (RH ≥ 90 % или осадки ≥ 0,2 мм).
- Статус означает «осмотреть первым», не диагноз и не рекомендацию обработки.
- Высокие объекты по DSM — гипотеза для осмотра на месте.
