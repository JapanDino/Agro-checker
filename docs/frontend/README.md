# Начни здесь: интерфейс Onlyfarms / AgroPulse

Передача второму разработчику, **10 ноября 2026**. Ветка
`J-D/frontend-handoff-dec04-2026`, исходный UI-срез `f2e1f29e`.
Этот комплект меняет документацию и инструкции агентов; новые модельные функции
из соседней ветки автоматически не переносились.

**Что нужно сделать разработчику:** улучшать интерфейс реального архивного
сценария, сохраняя геометрию, основания задач, историю и честные состояния недостатка
данных. Продукт для агронома — подготовка и фиксация обследования. Подтверждённого
прогноза болезней или пользы осмотров пока нет.

## Первые 15 минут

1. Прочитай [статус веток](BRANCH_STATUS.md): работающий сервер автора может показывать
   функции, которых нет в твоём checkout.
2. Запусти приложение по [инструкции установки](SETUP_AND_TROUBLESHOOTING.md) на
   отдельном порте и с отдельным техническим журналом.
3. Пройди [сценарий агронома и приёмку](USER_FLOWS_AND_QA.md), включая preview результата
   без записи посещения.
4. Для первой задачи используй [готовый запрос в Claude Code](AGENT_WORKFLOW.md#первый-запрос).

## Короткий ответ «что уже работает»

Карта 27 приблизительных обводок; архив 92 пригодных сцен Sentinel-2; сравнение
NDVI/NDMI с датами и облачными пропусками; выбор фиксированного окна 60 м;
задача с автором и вопросом; история места; запись настоящего результата и фото;
preview без записи; план до трёх разных мест и экспорт; два оформления с откатом.

Реальные осмотры и фото не предзаполнены. Контуры и культуры не подтверждены.
Карточка нового read-only прогноза и автоматический сбор новых снимков существуют
в модельной ветке, но отсутствуют в этой версии UI — см. матрицу веток.
