# Интерфейс архивного пилота

Реализован 12 октября 2026 года. Яблоня, заморозки, Краснодар; данные у станции 34929. Это историческое воспроизведение, не действующее предупреждение хозяйству.

## Запуск

В текущей папке данные уже собраны. Для сборки достаточно стандартной библиотеки Python:

```powershell
python -m agro_checker ui
```

Результат: `dist/pilot/index.html`. Один самостоятельный HTML-файл содержит интерфейс и снимок всех 368 ночей марта–мая 2022–2025. Его можно открыть обычным браузером без сервера и интернета. Каталог `dist/` исключён из Git; после изменения исходников или расчётов повторите сборку.

Для локального HTTP-просмотра:

```powershell
python -m agro_checker ui --serve --port 8765
```

Откройте http://127.0.0.1:8765/. Сервер слушает только loopback и отдаёт каталог собранного интерфейса, не весь репозиторий. Ctrl+C останавливает сервер. Встроенный браузер Codex принимает HTTP/HTTPS и блокирует `file://`; в нём проверен HTTP-вариант. Для файла без сервера используйте обычный браузер вручную.

На другом компьютере сначала подготовьте данные через `single-run`, как описано в [README](../README.md). При отсутствии результатов команда `ui` выдаёт ошибку и не подменяет данные сценарными числами. Альтернативные каталоги: `--data-dir`, `--output-dir`; конфигурация должна совпадать с расчётом.

## Основной экран

Над фильтрами — быстрый выбор трёх иллюстраций из отложенного сезона: попадание 2–3 марта 2025, пропуск 7–8 марта, ложная тревога коррекции 4–5 марта. Кнопки меняют дату/сезон и сбрасывают фильтр, сохраняя фазу и видимость наблюдений. Подпись выбранного примера объясняет результат. [Краткий сценарий показа](DEMO_SCENARIO.md). Это ретроспективно выбранные примеры по порогу 0 °C, не слепая проверка и не прогноз повреждения яблони.

- Сезон, дата вечера, предыдущая/следующая ночь, фильтры всех, холодных и неполных ночей. Последние два фильтра явно используют последующие наблюдения.
- Три ряда: GFS одного выпуска, выбранная коррекция, фактическая температура воздуха станции. Наблюдения можно скрыть; они также скрываются в минимумах, таблице и проверке по факту.
- График показывает разрывы вместо интерполяции пропусков, подсказку на часовой отметке, московское время и линию справочного порога. Стрелки выбирают отметку; Escape скрывает подсказку.
- При неполном ряде минимум всей ночи не устанавливается. Прогнозный риск не зависит от наблюдений и не меняется после их показа.
- Обучение, выбор метода и отложенная проверка подписаны отдельно. Фактические пропуски и ложные тревоги показываются после ночи по погодному порогу 0 °C, отдельно от порога яблони.
- Качество и источники раскрывают ухудшение почасовой ошибки, прежнее число пропусков, метод допуска архива, расстояние от ячейки до станции и контрольные суммы данных.

## Карточка яблони

Фаза изначально не выбрана. Пользователь явно задаёт сценарную фазу; фенология сада не восстановлена. Справочные значения взяты из строки яблони таблицы WSU, опубликованной Utah State University Extension в марте 2020 года, страница 1. Исходные °F переведены в °C без округления для сравнения; подписи округлены и отмечены `≈`.

Порог — справочный T10 для 30-минутного воздействия в таблице. Он не является предсказанной долей повреждений или потерей урожая. Почасовые температуры воздуха станции не подтверждают длительность экспозиции и температуру цветков. Карточка перечисляет часовые отметки у порога/ниже; непрерывная длительность и вероятность не вычисляются.

При достижении порога хотя бы одним прогнозом показывается возможный риск с объяснением. Если прогнозы порога не достигают, интерфейс не утверждает отсутствие риска в саду. При неполном прогнозе оценка ограничена. Справочник и карточка ещё не проверены агрономом для конкретного сада.

Подготовка включает проверку датчиков, людей, оборудования и регламента. Пилот не назначает запуск/остановку защиты или полива.

Источники: [USU / WSU, таблица](https://extension.usu.edu/productionhort/files/CriticalTemperaturesFrostDamageFruitTrees.pdf), [FAO, ограничения порогов](https://www.fao.org/4/y7223e/y7223e0a.htm), [FAO, активная защита](https://www.fao.org/4/y7223e/y7223e0d.htm).

## Код и проверка

Экспорт и сборка: `agro_checker/pilot_ui.py`; шаблон, стили и код: `web/pilot/`; справочник: `config/apple_thresholds.json`. При работе интерфейса нет внешних JavaScript-библиотек, шрифтов или сетевых запросов. CSP запрещает соединения; внешние источники открываются только по нажатию ссылки.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
node --test tests/test_risk.cjs
```

Проверены выбор фаз/дат/сезонов, пропущенный заморозок 9–10 марта 2024, неполная ночь 26–27 марта 2024, пустой фильтр 2022, скрытие наблюдений, клавиатура и ширина 375/1440 px. Работа самостоятельного файла проверена по встроенным ресурсам и отсутствию сетевых загрузок; автоматическое открытие `file://` встроенным браузером недоступно.
