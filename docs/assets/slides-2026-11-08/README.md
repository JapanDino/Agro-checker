## Что важно подписать на слайдах

- Очередь построена на **демонстрационном примере** учёта (все поля подписаны «ПРИМЕР»)
  и архивной погоде ERA5 за 20 мая 2024. ERA5 — реанализ, общий для сектора, не измерение
  на поле.
- Пороги риска — черновик команды для проверки на пилоте 2027, не проверенная модель
  болезней. Статус означает «осмотреть первым», а не диагноз или совет обрабатывать.
- Высокие объекты рядом с полем на снимке 07 — гипотеза по DSM 30 м, проверяется на месте.
- Сводка «заявлено / работает»: [PRODUCT_CAPABILITIES.md](../../PRODUCT_CAPABILITIES.md).

## Как переснять

Запустить `START_SCOUTING.cmd` на пустом журнале, открыть
`http://127.0.0.1:8770/scouting?design=pulse`, «Сегодня» → «Пример», дата 20.05.2024.
